# The Talks

## Symfony for The Aspiring PHP Musician - James Leeson

> What is the Symfony Framework and how can we use it develop web apps? This talk is targeted for those who have never used Symfony and/or PHP. We’ll start by diving into the very basics of what it is, the benefits, and how we can easily use it. Next we’ll how we can extend our project with ease to add CRUD capabilities and expose an API. I hope you can leave the talk with a better view of what I think makes Symfony great and some next steps for furthering learning.
