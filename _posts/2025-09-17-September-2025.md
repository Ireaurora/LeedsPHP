# The Talks

## Level up with Rector and PHPStan – Peter Fox

> This talk will guide you through how to put both wonderful PHP tools to work. We’ll learn how to use PHPStan to stop doing the bad things we don’t like, while equally using Rector to level up and improve our large codebases.
Through this talk I will teach you had to setup PHPStan for non-type coverage situations, how to write up your own PHPStan rules and test them. Then get into how to use Rector to incrementally remove dead code and automate improving your code base with newer syntax and implement more type hints.
